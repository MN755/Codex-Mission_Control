# Support

Use GitHub issues for bug reports, feature requests, and documentation problems.

## Before opening an issue

- confirm the problem on the current branch when practical
- include environment details such as OS, shell, and runner type
- include safe diagnostics and reproduction steps
- do not include secrets, private keys, raw tokens, or `.env` contents

## Security issues

Use [SECURITY.md](SECURITY.md) for vulnerability reporting guidance. Do not post sensitive security details publicly.

## Helpful context

- whether you are using Codex chat mode
- whether the daemon health check passes
- whether the problem affects install, attach, approvals, runners, or handoff
- relevant error summaries, not raw secret-bearing logs
