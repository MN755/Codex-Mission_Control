# Copy Paste Codex Prompts

This page collects copyable prompts for the most common Mission Control chat workflows.

> Status: Reference

## Install Mission Control

```text
Install Mission Control from https://github.com/MN755/Codex-Mission_Control and wire it up for this workspace.
```

## Attach current repo

```text
Attach the current workspace to Mission Control.
```

## Use Mission Control for this repo

```text
Use Mission Control for this repo.
```

## Show status

```text
Show Mission Control status.
```

## Show pending approvals

```text
Show pending Mission Control approvals.
```

## Answer approval

```text
Approve once for the current pending Mission Control decision.
```

Alternative:

```text
Deny the current pending Mission Control decision and tell me the next safe option.
```

## Debug stuck orchestration

```text
Mission Control looks stuck. Diagnose it and show me the recovery options.
```

## Get handoff

```text
Get the latest Mission Control handoff.
```

## Enable safe mode

```text
Put this Mission Control project into strict safe mode.
```

## Import existing codebase

```text
Use Mission Control to understand this existing repo in read-only mode before edits.
```

## Use subagent burst

```text
Ask Mission Control Manager whether this task should use a larger worker burst, and show me the swarm recommendation before any scale-up approval.
```
