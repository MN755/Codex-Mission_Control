# Quick Start

> Status: Current

This page covers the fastest path from a local repo to a working Mission Control session in Codex chat.

## Recommended flow

From a Codex chat in your project folder:

```text
Install Mission Control from https://github.com/MN755/Codex-Mission_Control and wire it up.
```

Then:

```text
Use Mission Control for this repo and fix the failing tests.
```

## Common prompts

Attach the workspace:

```text
Attach the current workspace to Mission Control.
```

Check status:

```text
Show Mission Control status.
```

Ask for the compact operator view:

```text
Show Mission Control operator snapshot.
```

Ask for release readiness:

```text
Show Mission Control verification brief.
```

Review pending decisions:

```text
Show pending Mission Control approvals.
```

Get the handoff:

```text
Get the latest Mission Control handoff.
```

Route a browser task through the optional Webwright lane:

```text
Use Mission Control for a browser task with Webwright when available.
```

## Typical happy path

1. Install or repair Mission Control for background running.
2. Run a health check.
3. Attach the workspace.
4. Start or resume the task.
5. Answer pending decisions when Mission Control asks.
6. Review the handoff.
