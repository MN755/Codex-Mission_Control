# Code of Conduct

## Our commitment

We want this project to be a respectful, professional, and useful place to collaborate. Contributors should act in good faith, communicate clearly, and focus on constructive technical work.

## Expected behavior

- be respectful and professional
- accept feedback in good faith
- keep discussions focused on the work
- report security-sensitive issues through the security policy, not public threads

## Unacceptable behavior

- harassment or abusive language
- doxxing or sharing private information
- publishing secrets, credentials, or exploit details in public
- disruptive behavior that prevents normal collaboration

## Reporting

If you need to report a conduct issue, contact the repository maintainers through the project's GitHub channels. When possible, include links or screenshots and keep private information out of public threads.
